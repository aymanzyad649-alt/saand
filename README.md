# مركز سند الطبي — موقع حجز مواعيد وفحوصات

نموذج واجهة عربي (RTL) لمركز طبي، مبني بـ HTML + CSS + JavaScript فقط وبدون أدوات بناء.
كل بيانات الأطباء والأسعار والمواعيد والاتصال تجريبية. لا يوجد نظام حجوزات حقيقي أو قاعدة بيانات؛ لا تستخدمه لجمع بيانات مرضى أو بيانات شخصية حقيقية.

---

## التشغيل

**الأسهل:** افتح `index.html` بالضغط المزدوج عليه.

**أو عبر سيرفر محلي** (مستحسن لتجربة أكثر واقعية):

```bash
python -m http.server 5500
```

ثم افتح `http://localhost:5500`.

## المزايا

### الحجز
- معالج حجز من 4 خطوات: **الخدمة ← الموعد ← بياناتك ← التأكيد**.
- تبويبان للخدمات: **استشارة طبية** (8 تخصصات / 8 أطباء) و**فحص أو تحليل** (10 تحاليل وأشعة).
- عرض تجريبي للأوقات حسب جداول ثابتة في `app.js`، وليس حسب توافر المركز الفعلي.
- إشغال تجريبي ثابت لبعض الأوقات، والحجوزات المحفوظة محليًا لا تُشارك بين الأجهزة.
- خيار **الزيارة المنزلية** للفحوصات (+50 ج.م) مع تحديث السعر فورًا.
- تحقق أساسي من الاسم ورقم الموبايل المصري والموافقة.
- كود حجز تلقائي بصيغة `SND-####`.
- شريط حجز سريع أعلى الصفحة (تخصص + ميعاد ← يفتح المعالج جاهزًا).

### بعد الحجز
- **مواعيدي**: قائمة محلية على الجهاز مع الإلغاء والطباعة؛ ليست متاحة للمركز أو على أجهزة أخرى.
- **أضف إلى التقويم**: ملف `.ics` يعمل مع Google Calendar و Outlook و Apple Calendar.
- **مشاركة التفاصيل**: تفتح قائمة مشاركة واتساب برسالة تجريبية ولا ترسلها إلى المركز.
- **طباعة**: إيصال أنيق مخصص للطباعة (بعيدًا عن تصميم الصفحة).

### الواجهة
- تصميم فاخر بألوان النعناع والتركواز، خطوط Cairo و Tajawal، أيقونات Bootstrap Icons.
- متجاوبة بالكامل من 360px حتى الشاشات الكبيرة، مع شريط سفلي للجوال.
- أسئلة شائعة (Accordion)، آراء مرضى، إحصائيات متحركة، وحركات ظهور عند التمرير.
- دعم أساسي لإمكانية الوصول: تسميات ARIA واحترام `prefers-reduced-motion`؛ يلزم اختبار شامل قبل الاستخدام الإنتاجي.

## كيف يعمل محرك المواعيد؟

1. كل طبيب له `days` (أيام العمل) و`hours` (من/إلى)، والمعمل له جدول أوسع.
2. تُولَّد الأوقات كل 30 دقيقة داخل ساعات العمل.
3. يُحسب إشغال تجريبي ثابت (Seeded) لكل (طبيب/فحص + تاريخ + وقت) بنسبة ~30%.
4. تُحفظ إدخالات النموذج في `localStorage` لهذا المتصفح فقط، ولا تُرسل إلى المركز.
5. لا يمكن حجز وقت في الماضي أو في يوم إجازة.

> كل تأكيد ظاهر في الموقع تجريبي وليس حجزًا حقيقيًا. لا يوجد سيرفر أو قاعدة بيانات أو مزامنة بين الأجهزة.

### شكل بيانات الحجز

```json
{
  "id": "SND-1234",
  "type": "doctor",           // doctor | test
  "title": "د. سارة عبد الرحمن",
  "subtitle": "استشاري القلب والأوعية الدموية",
  "date": "2026-11-03",
  "time": "11:30",
  "patient": { "name": "أحمد محمد", "phone": "01001234567", "notes": "" },
  "price": 400,
  "visit": "center",          // center | home (للفحوصات فقط)
  "createdAt": 1761700000000
}
```

لمسح كل الحجوزات التجريبية من المتصفح:

```js
localStorage.removeItem('sanad_bookings_v1');
```

## نقاط التخصيص

| ما تريد تغييره | المكان |
| --- | --- |
| أسماء التخصصات | `SPECIALTIES` في `app.js` |
| الأطباء (الاسم، السعر، الأيام، الساعات، التقييم) | `DOCTORS` في `app.js` |
| التحاليل والأسعار ومدة الفحص | `TESTS` في `app.js` |
| مواعيد المعمل | `LAB` في `app.js` |
| سعر الزيارة المنزلية | `HOME_VISIT_FEE` في `app.js` |
| رقم واتساب المركز | `CLINIC_PHONE` في `app.js` |
| رقم الهاتف والعنوان في الصفحة | `index.html` (قسم التواصل والفوتر) |
| الألوان والخطوط والظلال | متغيرات `:root` في أول `style.css` |
| النصوص التعريفية والأسئلة الشائعة | `index.html` |

## ملاحظات مهمة

- **بيانات تجريبية:** أسماء الأطباء والأسعار والعنوان والهاتف (`0100 123 4567`) وأرقام الواتساب والتقييمات والإحصاءات أمثلة للعرض فقط — استبدلها ببيانات موثقة قبل النشر.
- **لا يوجد دفع أو حجز فعلي:** الأسعار للعرض فقط، ولا تتم أي معاملة مالية.
- **لا يوجد باك-إند:** لا يمكن تأكيد أو حجز موعد حقيقي أو منع التعارض بين أجهزة الزوار. يتطلب ذلك API وقاعدة بيانات موثوقة ومراجعة أمنية.
- **الخصوصية:** لا تُدخل بيانات صحية أو شخصية حقيقية في هذه النسخة. الحجوزات التجريبية تُحفظ محليًا في المتصفح فقط.
- **الخطوط والأيقونات** تُحمَّل من Google Fonts و jsDelivr؛ تحتاج اتصالًا بالإنترنت لأول تحميل (أو استضفها محليًا لموقع بلا إنترنت).
- أضف سياسة خصوصية وشروط استخدام قبل الاستخدام الفعلي مع المرضى.

## أفكار للتطوير

- لوحة تحكم للطبيب/الاستقبال لإدارة المواعيد.
- تذكير تلقائي عبر SMS أو واتساب قبل الموعد.
- تسجيل الدخول برقم الموبايل + OTP لعرض «مواعيدي» على أي جهاز.
- ربط بوابة دفع لتحصيل رسوم الحجز.
- دعم اللغة الإنجليزية (تبديل `dir="ltr"`).
